Target MVS version (dev + industrial PC)
=======================================
MVS:                 4.6.3 Build 20260205
Industrial Camera SDK: 4.7.1.1 Build 20260129
Frame Grabber SDK:     2.7.1.1 Build 20260129

Install path (Windows x64):
  C:\Program Files (x86)\MVS\
Runtime DLL:
  C:\Program Files (x86)\Common Files\MVS\Runtime\Win64_x64\MvCameraControl.dll

Setup checklist
1. Install the same MVS version on every machine (dev + industrial PC).
2. Open MVS client, confirm GigE preview, then CLOSE the client before this app opens the camera.
3. Project MvImport is copied from:
     ...\MVS\Development\Samples\Python\MvImport
   Refresh with:
     powershell -ExecutionPolicy Bypass -File .\deploy\copy_mvs_sdk.ps1
   Then re-check that MvCameraControl_class.py still has the multi-path DLL loader patch.
4. Start Django, open /detection/realtime/, choose GigE device, Start.

Optional env overrides:
  set MVS_RUNTIME_DIR=C:\Program Files (x86)\Common Files\MVS\Runtime\Win64_x64
  set HIK_CAMERA_SDK_MVS_LIBRARY=C:\Program Files (x86)\Common Files\MVS\Runtime\Win64_x64\MvCameraControl.dll
