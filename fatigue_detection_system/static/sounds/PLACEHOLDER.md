# 声音文件目录

此目录用于存放系统需要使用的声音文件，包括：

1. `alert.mp3` - 一般警报声
2. `fatigue_alert.mp3` - 疲劳驾驶警报声
3. `phone_alert.mp3` - 打电话警报声
4. `smoking_alert.mp3` - 抽烟警报声

请将相应的声音文件添加到此目录中。

## 推荐网站

您可以从以下网站获取免费的声音文件：

- [Freesound](https://freesound.org/)
- [SoundBible](https://soundbible.com/)
- [Zapsplat](https://www.zapsplat.com/)

确保下载的声音文件为MP3格式，并重命名为上述文件名。
